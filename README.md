# Village Guys Halal

Lightweight static website for Village Guys Halal in Breinigsville, Pennsylvania. The site is plain HTML, CSS, and JavaScript and can be deployed directly from the repository root on Vercel with no build command or framework preset.

## Vercel deployment

1. Import this GitHub repository into Vercel.
2. Choose **Other** as the framework preset.
3. Leave the build command empty.
4. Leave the output directory empty so Vercel serves the repository root.
5. Add the production domain `villageguys.com` in Vercel after confirming ownership and DNS access.
